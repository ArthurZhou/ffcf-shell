## Default Permission

cf-optimizer 插件默认权限：允许全部命令

#### This default permission set includes the following:

- `allow-optimizer-get-status`
- `allow-optimizer-refresh`
- `allow-optimizer-resolve`
- `allow-optimizer-get-config`
- `allow-optimizer-set-config`
- `allow-api-request`
